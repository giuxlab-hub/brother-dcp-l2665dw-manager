## Version history

- **0.1.0:** first CUPS and Brother Web Based Management interface.
- **0.2.0:** Italian/English localization and language selector. Historical Debian executable lacks the Python interpreter header.
- **0.2.1:** restores `#!/usr/bin/python3` and preserves the bilingual interface.

## Repository additions

The repository contains the full GNU GPL v3 text in `LICENSE`, a bilingual `README.md`, release notes and a `packaging/` directory with the desktop launcher, icon and Debian metadata extracted from the v0.2.1 package.

The original v0.2.1 Python application is unchanged. In the GitHub checkout, only the output path of `build-deb.sh` differs from the author's original builder: the output is created in the local source directory instead of a fixed absolute home path. The unchanged builder is preserved in the source tarball.

Generated bytecode and private work files are not included.

## Verification scope

Archive SHA-256, package identity, script byte equality and Python syntax are checked. A separate build from the GitHub checkout verifies Debian package generation. This is not a physical printer, scanner or GTK acceptance test.
