# Brother DCP-L2665DW Manager for Linux

GTK3/CUPS desktop manager for the Brother DCP-L2665DW monochrome laser printer.

Features: CUPS status, driverless printing options, Draft/Normal/High diagnostic print, manual duplex choice, opening official Brother Web Based Management for toner/device status, XSane scanner launcher, official documentation link.

The program uses standard CUPS command-line tools and the official Brother web interface. It does not automate firmware updates, change printer passwords, or implement unverified proprietary protocols. Printer IP and CUPS queue are editable.

Build: `bash build-deb.sh`
